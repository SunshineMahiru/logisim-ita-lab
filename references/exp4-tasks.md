## 任务4：32 位桶形移位器（lab4.4，电路名 `Shifter32`）

### 引脚与隧道

| 引脚 | 宽 | 隧道 | 含义 |
|---|---|---|---|
| `DataIn` | 32 | `Din` | 移位数据 |
| `shamt` | 5 | `shamt` | 移位位数 |
| `L/R` | 1 | `Left/Right` | 0 右移，1 左移 |
| `A/L` | 1 | `Arth/Logic` | 0 逻辑，1 算术（右）/ 循环（左） |
| `DataOut` | 32 | `Dout` | 移位结果 |

### 功能表（由测试向量反推，题面文字与数据不一致处以数据为准）

| L/R | A/L | 功能 | 示例 `bbbbbbbb sh=7` |
|---|---|---|---|
| 0 | 0 | 逻辑右移，高位补 0 | `01777777` |
| 0 | 1 | 算术右移，高位补符号位 | `ff777777` |
| 1 | 0 | 逻辑左移，低位补 0 | `dddddd80` |
| 1 | 1 | **循环左移**（题面写「算术左移」，按数据实为 rotate） | `dddddddd` |

### 拓扑：5 级桶形

第 k 级移 `2^k` 位，由 `shamt[k]` 决定该级是否生效。

```
每级：
  候选① 逻辑右移 r：bit i = A[i+r]，i+r≥32 时取 fillR
  候选② 逻辑左移 r：bit i = A[i-r]，i<r 时取 0
  候选③ 循环左移 r：bit i = A[(i-r+32) % 32]
  fillR = A/L ∧ A[31]          一条 AND 门，本级所有填充位共用
  BL = MUX(A/L, ②, ③)          左移形态
  C  = MUX(L/R, ①, BL)         方向
  B  = MUX(shamt[k], A, C)     本级是否移位
```

**必须有的三层选择，缺一层就错**：

- 漏掉 `shamt[k]` 那层 → 五级无条件全生效，`ffffffff` 右移 1 位会算成右移 31 位（输出 `1`）；
- 漏掉 `A/L` 那层 → 算术右移退化成逻辑右移，循环左移退化成逻辑左移；
- 漏掉 `L/R` 那层 → 左右不分。

### 实现要点

- `shamt` 先拆位：`splitter((x,y), 5, 5, outs=['sh0'..'sh4'], in_label='shamt')`；
- 每级 = 4 个 `Splitter`（1 个拆本级输入，3 个做位映射）+ 3 个 `MUX32`；
- `MUX32`：lib3 `Multiplexer`，`width=32`、`select=1`；端口
  `in0(-30,-10) in1(-30,+10) sel(-20,+20) en(-10,+20) out(0,0)`，**en 接常量 1**；
- Splitter 扇出 32 时端口在 `(x+20, y-320+10i)`，每个端口需要 20px 导线 + 隧道；
- 成品 192 KB / 817 个 `<comp>` + 773 条 `<wire>`，传输要分段。

## 任务5：32 位 ALU（lab4.5，电路名 `ALU`）

### 引脚

`A(32) B(32) ALUctr(4)` → `S(32) Zero(1)`；文件内另有子电路 `ALUctrl`。
题面文字写的是 `A、B、ALUctrl` 与 `Result、Zero`，`.circ` 里的真实 label 是
`ALUctr` 与 `S`；驱动按 `.circ` 的 label 取值。

### ALUctr 编码 → 控制信号（题面最小项，直接照抄）

```
SUBctr = Σm(2,3,8)     SIGctr = m2        ALctr = m13     LRctr = m1
OPctr[2] = Σm(1,2,3,5,13,15)
OPctr[1] = Σm(2,3,4,6)
OPctr[0] = Σm(4,7,15)
```

### OPctr 选择码 → 运算（实测）

`000` 加法器、`001` 按位与、`010` 按位异或、`011` 按位或、`100` 移位器、`101` 操作数 B、
`110` 小于置 1；`111` 无任何编码使用。

这个顺序由向量反推得到：`ALUctr=4` 得 `ffffffff`（或）、`6` 得 `ffffffff`（异或）、
`7` 得 `00000000`（与），只有上述映射能同时解释三行。按「或、与、异或」的顺序记会全错。

### ALUctr 全 16 种编码（由最小项推导，逐条与向量核对）

| ALUctr | SUB | SIG | AL | LR | OPctr | 运算 |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 | 000 | `A + B` |
| 1 | 0 | 0 | 0 | 1 | 100 | 逻辑左移，位数 `B[4:0]` |
| 2 | 1 | 1 | 0 | 0 | 110 | 带符号小于置 1 |
| 3 | 1 | 0 | 0 | 0 | 110 | 无符号小于置 1 |
| 4 | 0 | 0 | 0 | 0 | 011 | 按位或 |
| 5 | 0 | 0 | 0 | 0 | 100 | 逻辑右移，位数 `B[4:0]` |
| 6 | 0 | 0 | 0 | 0 | 010 | 按位异或 |
| 7 | 0 | 0 | 0 | 0 | 001 | 按位与 |
| 8 | 1 | 0 | 0 | 0 | 000 | `A − B` |
| 9 | 0 | 0 | 0 | 0 | 000 | `A + B` |
| 10 | 0 | 0 | 0 | 0 | 000 | `A + B` |
| 11 | 0 | 0 | 0 | 0 | 000 | `A + B` |
| 12 | 0 | 0 | 0 | 0 | 000 | `A + B` |
| 13 | 0 | 0 | 1 | 0 | 100 | 算术右移，位数 `B[4:0]` |
| 14 | 0 | 0 | 0 | 0 | 000 | `A + B` |
| 15 | 0 | 0 | 0 | 0 | 101 | 操作数 B |

减法用加法器 + `SUBctr` 反码进位实现；`SIGctr` 只在 OPctr=110 时起作用。

**`Zero` 跟的是加法器，不是最终结果。** 实测两个点：

| A | B | ALUctr | S | Zero | 说明 |
|---|---|---|---|---|---|
| `00000005` | `00000005` | 3 | `00000000` | 1 | `A−B=0`，SLT 结果为 0 |
| `ffffffff` | `00000001` | 3 | `00000000` | 0 | SLT 结果为 0，但 `A−B≠0` |

所以 `Zero` 直接取 32 位加法器的为零标志即可，不要对最终 `S` 再判一次零；否则第二行会给
`Zero=1`。题面只说「零标志作为结果标志输出」，没有写这层细节。

## 复用清单

新做运放类实验时按此顺序：

1. 先看 `<lib desc="file#…">`，把依赖画成链，确认每个文件都在本工作区；
2. 缺的重画进本文件，不要跨实验引用（实验4 的 `lab4.4` 就是这样处理的）；
3. 用 `Dump` 确认电路名（不一定是 `main`）；
4. 先测底层（加法器/移位器），再测上层（ALU）；
5. 每关用题面向量逐行比对，`Zero` 这类单比特输出也要一起比。

## 复现与验收

向量表不是抄来的结论，以下两段可以重跑（环境变量见 `SKILL.md` 的「本地核对」）：

```python
import sys; sys.path.insert(0, 'scripts')
from runner import run, setline

# 任务4 第 07 行：循环左移 7 位
r = run('已完成目录/myshixun/lab4.4.circ', 'Shifter32',
        [setline({'DataIn': 0xbbbbbbbb, 'shamt': 7, 'L/R': 1, 'A/L': 1}), 'snap'])
print(r['snaps'][-1]['DataOut'])          # dddddddd

# 任务5 第 09 行：ALUctr=d，算术右移
r = run('已完成目录/myshixun/lab4.5.circ', 'ALU',
        [setline({'A': 0xffffffff, 'B': 0x80000000, 'ALUctr': 0xd}), 'snap'])
print(r['snaps'][-1])                     # {'S': 'ffffffff', 'Zero': '0'}
```

`snap` 输出是十六进制且不补前导零，`0x01777777` 会打成 `1777777`；比对时按整数比，
不要按字符串比。
